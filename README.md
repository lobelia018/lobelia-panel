# 🌺 LobeliaPanel

**LobeliaPanel** is a lightweight, standalone local GUI designed for trading, token creation, and interaction with **gang.fun**. Operating fully on `127.0.0.1`, it eliminates the risks associated with third-party browser extensions while ensuring maximum privacy and execution speed.

🌐 **Official Site:** [lobeliapanel.xyz](https://lobeliapanel.xyz)

---

## ✨ Key Features

- 🪙 **Token Creation Module:** Deploy and launch new tokens directly from your local interface in seconds.
- 🔒 **100% Local Execution:** Runs locally via a lightweight Python server. Your keys and session data stay on your machine.
- ⚡ **High-Speed Execution:** Direct HTTP request handling without the overhead of browser extension layers.
- 💎 **Glassmorphic UI:** Modern, clean, and intuitive dark-mode interface built for effortless navigation.
- 🛡️ **Zero Extension Risk:** Avoid malicious wallet drained vulnerabilities common in browser add-ons.
