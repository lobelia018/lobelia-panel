LobeliaPanel

A free local web panel for gang.fun. Browse live token lists, scan bonding curves with your own filters, and buy, sell or convert from your browser. Your Binance wallet signs everything.

No analytics or tracking
Never touches your private keys
Plain Python, readable code

🧭 What LobeliaPanel does

LobeliaPanel is a window onto the gang command-line tool. It shows what the CLI sees and runs the same commands you would type, one step at a time.

📡 Live token lists

Popular, New and Near graduation, refreshed every few seconds. A banner warns you when your gang CLI is out of date and may miss new tokens.

🔎 Scanner

Set curve progress, 24 h volume and volume-to-market-cap ratio. Matches are highlighted, with a sound alert when a new one appears.

💱 Buy and sell

Each step (wrap, approve, trade) is previewed and confirmed before the next. It stops if Binance flags a risk and waits for your decision.

📝 Optional public note

Add a short thought to a buy or sell. It is published on gang.fun with the trade, so it is public and permanent. Not available for GangLaunchpad (V3) tokens.

🔁 Convert BNB

Swap through the baw wallet CLI. When a pair has no stablecoin, it routes through USDT in two steps and tells you before it starts.

🖥️ Background terminal

See every command the panel runs, with timing and errors. The interface is available in Spanish, English and Chinese.

🛡️ Why a local panel instead of a browser extension?

Both can work well. They carry different risks, and this is the trade-off LobeliaPanel is built around.

Browser extension

  • Runs inside your browser with permission to read the pages you open
  • Updates can arrive automatically and change what it does
  • Its code is often a bundled build that is hard to read
  • If it is ever compromised, it sits next to your wallet pages

LobeliaPanel

  • Runs on your PC: only reachable at 127.0.0.1:8788
  • Readable code: plain Python in server.py, which you can read before running it
  • No private keys: signing goes through the baw wallet CLI and, when required, the Binance app
  • Updates only when you replace the files
  • Other websites can’t call it: every request needs a per-session token

Before you start, you need

  • Python 3 and Node.js installed
  • A Binance Agentic Wallet with a .ai Agent ID, with Developer Mode and “Trade all tokens” enabled in the Binance app
npm i -g @binance/agentic-wallet
npm i -g @gangfun/cli@latest
baw auth signin
Step 1

Extract the zip file into any folder on your PC.

Step 2

Double-click:

Start_LobeliaPanel.bat

or run:

python server.py
Step 3

Your browser opens at:

http://127.0.0.1:8788

Press “Sign in / verify session”.

🔒 What it connects to

Nothing is sent to the author of LobeliaPanel. These are the only outside services your computer talks to while it runs.

⌨️ The gang CLI

Reads token data from gang.fun and BNB Chain, and prepares each transaction. It never holds your keys.

📲 The baw wallet CLI

Signs through your Binance Agentic Wallet. When Binance requires it, you approve in the Binance app on your phone.

⛓️ Public BSC nodes

Used to read token balances. Like any wallet, those nodes can see your IP address and the address you query.

💲 Binance price API

Used only to show the BNB price in US dollars.
